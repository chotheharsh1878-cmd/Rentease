# RentEase – House Rental & Student Accommodation Platform 🏠🎓

Please refer to the main [README.md](../README.md) in the project root for full architecture documentation, setup commands, demo credentials, and API specifications.

### Quick Start Commands:
```powershell
# 1. Initialize and Seed MySQL Database
npm run db:init

# 2. Run Backend (from rentease/server)
npm start

# 3. Run Frontend (from rentease/client)
npm run dev
```
